# Content Design System — منصة البيان

> وثيقة تصميم المحتوى الموحد لمركز المعرفة (Knowledge Center)
> الإصدار: 1.0 | آخر تحديث: يوليو 2026

---

## مقدمة

هذه الوثيقة تحدد **قواعد كتابة وهيكلة المحتوى** لجميع صفحات مركز المعرفة في منصة البيان. الهدف منها ضمان الاتساق البصري والأسلوبي عبر جميع الصفحات، سواء كان لدينا 7 صفحات أو 70.

---

## 1. أنواع الـ Sections

كل صفحة في مركز المعرفة تتكون من مجموعة من **الـ Sections**. كل Section له غرض محدد وقواعد كتابة ثابتة.

| # | الـ Section | الغرض |
|---|-------------|-------|
| 1 | Hero | العنوان الرئيسي والوصف المختصر |
| 2 | Timeline | عرض المراحل بتسلسل زمني |
| 3 | Checklist | قائمة فعلية للمهام |
| 4 | Information | محتوى تعليمي أو شرح |
| 5 | Warning | تحذير مهم |
| 6 | Tip | نصيحة عملية |
| 7 | LegalReference | مرجع قانوني (مادة/لائحة) |
| 8 | ComparisonTable | جدول مقارنة |
| 9 | FAQ | سؤال وجواب |
| 10 | CTA | دعوة لاتخاذ إجراء (تدريب/اختبار) |
| 11 | RelatedArticles | روابط لصفحات ذات صلة |
| 12 | OfficialSources | المصادر الرسمية |
| 13 | Divider | فاصل بين الأقسام الرئيسية |

## 2. قواعد كل Section

### 2.1 Hero

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | افتتاحية الصفحة — تعریف بالصفحة في 3 أسطر كحد أقصى |
| المكون | `GuideHero` |
| المحتوى | عنوان + سطر أو سطرين وصف |
| الـ CTA | زر واحد فقط — اختياري |
| العدد | **مرة واحدة فقط** في أعلى الصفحة |
| الطول | لا يزيد عن 60 كلمة |
| مثال | "دليل شامل ليوم الامتحان الإلكتروني لمسابقات الجهاز المركزي للتنظيم والإدارة، من تجهيز المستندات إلى داخل اللجنة وبعد الانتهاء." |

### 2.2 Timeline

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | عرض مراحل أو خطوات بتسلسل زمني أو منطقي |
| المكون | `JourneyTimeline` + `JourneyStep` |
| المحتوى | 4-11 خطوة — كل خطوة بعنوان ووصف قصير |
| العدد | 0-2 مرات في الصفحة |
| التفاعل | كل خطوة قابلة للنقر → تنتقل إلى صفحة مستقلة |
| الطول | كل خطوة: 5-15 كلمة وصف |
| مثال | الخطوات: الإعلان ← التقديم ← الامتحان ← النتيجة ← التعيين |

### 2.3 Checklist

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | قائمة مهام يجب على المستخدم تنفيذها |
| المكون | `GuideChecklist` |
| المحتوى | عناصر تبدأ بفعل أمر (جهز، اقرأ، احفظ، تأكد) |
| العدد | 3-7 عناصر |
| التنسيق | كل عنصر مع checkbox |
| الطول | كل عنصر: 5-15 كلمة |
| مثال | "□ جهز بطاقة الرقم القومي الأصلية" |

### 2.4 Information

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | شرح أو تعليم — المحتوى الأساسي للصفحة |
| المكون | `GuideSection` |
| المحتوى | فقرات قصيرة + قوائم + جداول — لا فقرات طويلة |
| العدد | مفتوح — العمود الفقري للصفحة |
| الطول | كل فقرة: 2-4 أسطر كحد أقصى |
| التنسيق | استخدم القوائم النقطية والجداول بدلاً من الفقرات الطويلة |

### 2.5 Warning

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | تحذير — شيء قد يسبب خطأ أو ضرراً إذا تجاهله المستخدم |
| المكون | `WarningBox` |
| اللون | أصفر/برتقالي — رمز ⚠️ |
| المحتوى | تحذير مباشر — لا مجاملات |
| العدد | 0-3 مرات في الصفحة |
| الطول | لا يزيد عن 4 أسطر |
| مثال | "لا تعتمد على منشورات وسائل التواصل — اقرأ الإعلان كاملاً من المصدر الرسمي." |

### 2.6 Tip

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | نصيحة عملية — معلومة تساعد المستخدم |
| المكون | `TipBox` |
| اللون | أخضر — رمز 💡 |
| المحتوى | قصير ومباشر |
| العدد | 0-5 مرات في الصفحة |
| الطول | سطر إلى سطرين |
| مثال | "احفظ رقم التسجيل في مكان آمن — صورته في الهاتف + نسخة ورقية." |

### 2.7 LegalReference

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | الاستشهاد بقانون أو لائحة |
| المكون | `LegalReference` |
| المحتوى | المادة + ملخصها + مصدرها |
| العدد | 0-4 مرات في الصفحة |
| التنسيق | "حسب المادة X من قانون Y: ..." |
| مثال | "حسب المادة 38 من اللائحة التنفيذية: تعلن النتيجة خلال شهر على الأكثر." |

### 2.8 ComparisonTable

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | مقارنة بين حالتين أو أكثر |
| المكون | `ComparisonTable` |
| المحتوى | صفوف بعمودين/ثلاثة |
| العدد | 0-2 مرات في الصفحة |
| مثال | جدول: النظام القديم ← النظام الجديد |

### 2.9 FAQ

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | سؤال وجواب — لمعلومات سريعة |
| المكون | `FAQAccordion` |
| المحتوى | سؤال قصير + جواب 2-4 أسطر |
| العدد | 3-15 عنصراً |
| التنسيق | Accordion — قابل للطي |
| مثال | "كيف أعرف موعد الامتحان؟ ← يتم إعلانه على بوابة الوظائف الحكومية..." |

### 2.10 CTA

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | دعوة لاتخاذ إجراء — ربط المستخدم بالمنصة |
| المكون | `EmbeddedCTA` |
| المحتوى | عنوان + سطر وصف + زر واحد |
| العدد | **مرة واحدة** في نهاية المحتوى الرئيسي |
| اللون | بارز — يلفت الانتباه |
| الموقع | نهاية المحتوى، قبل المصادر |
| مثال | "هل تريد تجربة محاكاة مشابهة؟ ← ابدأ التدريب الآن" |

### 2.11 RelatedArticles

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | روابط لصفحات ذات صلة |
| المكون | `RelatedLinks` |
| المحتوى | 3-6 روابط مع عنوان مختصر |
| العدد | مرة واحدة |
| الموقع | قبل المصادر |
| مثال | "اقرأ أيضاً: دليل يوم الاختبار، كيف يعمل الامتحان" |

### 2.12 OfficialSources

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | المصادر الرسمية التي اعتمد عليها المحتوى |
| المكون | `OfficialSources` |
| المحتوى | جدول: المصدر + الرابط |
| العدد | مرة واحدة — في أسفل الصفحة |
| الموقع | نهاية الصفحة |
| إلزامي | **نعم** — كل صفحة يجب أن تذكر مصدرها الرسمي |

### 2.13 Divider

| القاعدة | القيمة |
|---------|--------|
| الوظيفة | الفصل بين الأقسام الكبرى في الصفحة |
| المكون | `SectionDivider` |
| الشكل | خط أفقي مع رقم القسم (إن وجد) |

## 3. ترتيب الـ Sections في الصفحة

### القاعدة العامة

```
Hero
    ↓
[Timeline OR Checklist]   ← (اختياري — حسب الصفحة)
    ↓
Information               ← (المحتوى الرئيسي، قسم أو أكثر)
    ↓
[Tips + Warnings]         ← (متفرقة داخل المحتوى الرئيسي)
    ↓
FAQ                       ← (اختياري)
    ↓
CTA                       ← (إلزامي)
    ↓
RelatedArticles           ← (اختياري)
    ↓
OfficialSources           ← (إلزامي)
```

### الترتيب حسب نوع الصفحة

| نوع الصفحة | الترتيب |
|------------|---------|
| دليل (Guide) | Hero → Checklist → Information → Tips/Warnings → FAQ → CTA → Related → Sources |
| رحلة (Journey) | Hero → Timeline → Information → Tips → CTA → Related → Sources |
| أسئلة شائعة (FAQ) | Hero → FAQ (مجمعة في أقسام) → CTA → Sources |
| مصادر (Resources) | Hero → Information (جداول) → CTA → Sources |

## 4. اسلوب الكتابة (Tone of Voice)

| القاعدة | الشرح |
|---------|-------|
| أنت توجيهي | استخدم "افعل، اجهز، تأكد" — ليس "يمكنك أن تفعل" |
| مختصر | لا فقرة تزيد عن 4 أسطر |
| مباشر | لا مقدمات طويلة — اذهب إلى المعلومة مباشرة |
| محايد | معلومات رسمية مدعومة بمصادر — لا آراء شخصية |
| دقيق | لا تعميم — "قد تختلف" وليس "تختلف دائماً" |
| واضح | الجمهور العام — لا مصطلحات قانونية معقدة دون شرح |

### أمثلة

| ❌ خطأ | ✅ صحيح |
|--------|---------|
| "يمكن للمتقدم أن يقوم بتجهيز المستندات..." | "جهز المستندات الآتية:" |
| "هناك العديد من الأمور التي يجب مراعاتها..." | "قبل الخروج، تأكد من:" |
| "بناءً على ما ورد في القانون..." | "حسب المادة 12 من قانون الخدمة المدنية:" |

## 8. قواعد عامة

| القاعدة | التفصيل |
|---------|---------|
| المحتوى الخام | في مجلد `content/` — Markdown بمقدمة (Front Matter) |
| الصفحات النهائية | في `resources/js/pages/guide/` — React + Inertia |
| المكونات | في `resources/js/components/guide/` — React |
| التصميم | RTL، خط Cairo، ألوان المنصة |
| المصادر | كل معلومة تُستند إلى مصدر رسمي |
| التحديث | كل ملف Markdown له `lastReviewed` في Front Matter |

## 9. Borderline Cases

### ماذا تفعل عندما لا ينطبق Section على الصفحة؟
بسّط. ليست كل الصفحات تحتاج Timeline أو Checklist. احذف الـ Sections غير الضرورية.

### ماذا تفعل عندما تحتاج Section غير موجود في القائمة؟
أضفه إلى هذه الوثيقة أولاً مع تحديد قواعده، ثم أنشئ المكون.

### ماذا تفعل عندما يكون المحتوى طويلاً؟
قسّمه إلى أقسام فرعية. استخدم ComparisonTable أو قوائم نقطية بدلاً من الفقرات.

## 10. أمثلة تطبيقية

### مثال: صفحة "يوم الاختبار"

```
Hero: "دليل يوم الاختبار — من البيت إلى اللجنة"
    ↓
Checklist: "قبل الخروج من المنزل — 5 أشياء تأكد منها"
    ↓
Information: "عند الوصول → داخل القاعة → بعد الانتهاء"
    ↓
Warning: "لا تحضر الهاتف المحمول إلى القاعة"
    ↓
Tip: "احضر قبل الموعد بساعتين"
    ↓
FAQ: 5 أسئلة شائعة
    ↓
CTA: "جرّب محاكاة الامتحان"
    ↓
Sources: بوابة الوظائف الحكومية، الجهاز المركزي
```

### مثال: صفحة "رحلة المتقدم"

```
Hero: "رحلة المتقدم إلى الوظيفة الحكومية"
    ↓
Timeline: 11 مرحلة (كل مرحلة تنقل إلى صفحة مستقلة)
    ↓
Information: شرح كل مرحلة (مقسمة إلى 11 قسماً)
    ↓
Tips: نصائح عامة
    ↓
ComparisonTable: ما الذي قد يختلف بين المسابقات
    ↓
CTA: "ابدأ رحلتك الآن ← سجل أو تدرب"
    ↓
Sources: قانون 81، اللائحة 1216، البوابة الرسمية
```

## ⚠️ تنبيه مهم

هذه الوثيقة **ليست ثابتة**. إذا اكتشفت أثناء بناء الصفحات أن Section معين لا يعمل، أو أن قاعدة معينة تحتاج تعديل — عدّل الوثيقة أولاً، ثم طبّق التعديل على جميع الصفحات. هذا يضمن بقاء النظام متسقاً مع نمو المحتوى.
